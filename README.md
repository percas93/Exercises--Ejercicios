# Exercises Repository
This repository is a growing collection of programming exercises and challenges. Its main purpose is to demonstrate my problem-solving process and coding style to potential employers and collaborators.

## 🎯 Purpose
Showcase how I approach problems step by step.
Share a variety of solutions as I continue practicing and learning.
Document progress and improvements over time.
Provide recruiters and reviewers with a clear view of my logical and analytical thinking.

## 📂 Structure
Exercises are currently numbered and added as I work on them. They’re not organized by topic or platform yet—the focus is on keeping a steady practice flow and showing real work as it develops.

## 🚀 How to Navigate
Browse the numbered exercises.
Open any file to read the problem statement and my solution.
Some exercises include multiple solution attempts to illustrate the reasoning process.

## 🌐 Language Choice
The repository is written in English to make it accessible and understandable to a wider audience. Variable names, comments, and documentation also follow this decision, keeping the code cohesive and consistent.

## 🔎 Why This Repository Matters
This repo is intentionally raw and transparent. It’s about showing the process, not just polished results. Recruiters and collaborators can:
Observe how I break down challenges.
See how I iterate, refine, and optimize.
Get a sense of my coding discipline, style, and growth.
